# Aura Suite

Free everyday Windows apps and AI web tools, rebuilt from scratch. By Aura Ventures.

| Folder | What it is |
|---|---|
| `apps/deskcal` | DeskCal, a calendar that reminds you (Tauri) |
| `apps/inkboard` | Inkboard, a whiteboard and notebook (Electron) |
| `site` | The hub site: apps, downloads and help. Edit `site/config.js` when something ships |
| `docs/OWNER-MANUAL.md` | How everything is run, deployed and released |
| `.github/workflows/release.yml` | Builds both Windows installers and publishes a GitHub Release on a `v*` tag |

The web tools (Aura Design, Speak AI, BeatBeater, SponsorFit, Codex Vitae) live in their own repos.

User help: `site/help.html`.
