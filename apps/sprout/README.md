# Aura Sprout

Gentle reading buddy for children. Parent-gated. Local-first PWA.

## Privacy by design (DPDP, under-18)
- Only a first name and star counts are stored, on the device.
- Reading practice uses the browser's own speech recognition. Sprout never records, stores or uploads audio.
- Parent screen sits behind a simple sum. Verifiable parental consent is required before any cloud sync is added.
